# FitFlow Frontend

This directory contains the frontend implementation of the FitFlow Redesign project.

## Selected Technology
React Native

## Purpose
The frontend provides the user interfaces for the FitFlow fitness application, including:

- User onboarding and profile management
- AI-generated personalized workout plans
- Workout tracking
- Nutrition logging
- Social community features
- Progress dashboards
- Notifications

React Native was selected to support efficient cross-platform development for both Android and iOS.
